# Unsupported deployment note

CourtSight's supported deliverable is the local single-server video demo. It
requires the React frontend to be built before Flask starts; the repository does
not include a verified Railway, Render, Vercel, or Netlify deployment workflow.

Follow the repository root [README](README.md) for the supported Python 3.11 and
Node 20.19+ setup, required model files, sample video, and run commands.
